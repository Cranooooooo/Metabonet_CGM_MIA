## 一、研究问题的由来

**总问题**：在 CGM 时序生成任务中，发布出的合成数据会不会泄漏「某个受试者是否在训练集里」。

**第一阶段（群体层面）**：把全部受试者随机等分成 2/4/6/8/10 个 cluster，用「包含该 cluster
的生成器」与「不包含的生成器」构造正负例。多个生成器、多个模型规模，三通道数据
（CGM、Basal/kg、Bolus/kg）。

结论两条：

- 所有生成器均无明显 MIA 风险，**而且不是因为攻击器太弱**
- **群体层面的平均会稀释个体风险**

第二条直接导出了下一步：既然平均会稀释，就应该去找最可能泄漏的那部分人。

---

## 二、转向 outlier

无法对 800–1300 个受试者逐一做 MIA（每人需要两个生成器）。直觉是：**在某些指标分布上
处于极端的受试者，泄漏风险应当更高**。

**要回答的问题**：outlier 的 MIA 风险是否显著高于 normal？

## 四、outlier 的选择

**14 个方法，13 个候选**（E13「天数计数」是负对照，不参与投票）：

- A 组（4 个）临床共识指标：TIR、CV、MAGE、GRI 等，定义在 mg/dL 血糖上
- B 组（4 个）曲线形状：CID-DTW 到 medoid、glucotype 份额、原始 k-NN（均值/最大）
- C 组（3 个）整体分布：MMD（原始空间 / TS2Vec 空间）、切片 Wasserstein
- D 组（1–2 个）学习表示：TS2Vec + LOF
- E 组（2 个）对照：天数计数、留自身外的 MMD

**判据**：在**多数候选方法**（13 个中至少 7 个）的**前 5%** 内。整套流程换 4 个随机种子
各跑一遍，只保留四次都入选的：**28 → 24 → 20**。

### 为什么是单侧 top 5%

不是因为分布形状，而是**统计量本身是单侧的**：13 个候选里 12 个是距离或距离类的非负量，
距离的下尾是「离中心最近」，即最典型的人。双侧各取 2.5% 会把最普通的人选进来。
唯一的例外 A2（CV − 36）是有符号量，但国际共识对「不稳定血糖」的定义本身是单侧的。

实测分布形状（14 个方法的偏度）：**8 个是重右尾**（A1 偏度 19.15、峰度 505），
3 个右偏，2 个近似对称，1 个左偏（A2）。

### 阈值敏感性

多数规则（≥7/13）不依赖数据即可事先指定。放宽或收紧一档的人数（四种子平均，
单通道/三通道）：≥6 → 55/38，**≥7 → 44/23.5**，≥8 → 33/15。名单是嵌套的：
把截断从 5% 移到 4% 或 6%，每个方法的入选集合都平滑变化（重合度 81% / 100%，
等于算术上的 4/5 与 5/5），所以这个截断点不脆弱。

## 五、两个问题，两套度量

这项研究回答两个不同的问题。它们的数据、特征、指标都不同，**不能混用同一个数字**。

```
问题一（威胁）  现实攻击者能否判定某人在训练集里
问题二（科学）  outlier 是否比 normal 更容易被识别 / 被记住
```

### 共同的训练资产

```
base        在 835 人背景上训练（不含任何目标）
include_t   在 背景 ∪ {t} 上训练，t 是 40 个目标之一
每 replicate 41 个模型，3 个独立 replicate 共 123 个
```

控制组是**先从背景中抽出**再各自训练 include 的，因此两臂的每一对形式相同
（对称配对，推导见 `docs/DESIGN.md`）。三个 replicate 的控制组互不重叠——组内 40 个目标
共用一个 base，其读数相关，**独立单元是 replicate 而非目标**。

## 六、问题一：MIA —— 现实攻击者能否判定成员身份

### 威胁模型

攻击者手里只有**一份发布出的合成数据集 S**，和某个人的真实记录 R_t。他要判断 t 是否在
训练集里。**他没有「没训练 t 的那个模型」**——那个东西在现实中不存在。

### 数据

- 正例：t 的窗口，配 `include_t` 发布的 S
- 负例：t 的窗口，配 `base` **以及若干 `include_u`（u ≠ t）** 发布的 S

负例跨多个发布集是必要的：若正例全来自 `include_t`、负例全来自 `base`，分类器可以靠
「认出这是哪一次训练」来分类，完全不需要成员信息。跨多个负例集之后，没有任何单一发布集
的属性能预测标签。

### 特征（每个窗口对 S 计算，10 维）

```
euc_min  euc_avg  euc_q01  euc_q05  euc_ball    到 S 的欧氏距离族
knn5     knn20    softmin                       k 近邻与软最小
cos_max  cos_ball                               余弦相似度族
```

`euc_ball` / `cos_ball` 的半径**取自真实窗口之间的距离**，不依赖任何模型——若从本次调用
自己的距离推导，成员与非成员条件会拿到不同阈值，那是特征自己造出来的混淆。

### 指标

**逐受试者 AUC**：对每个人训练一个分类器，用它对该人的窗口打分，算成员/非成员的 AUC。
0.5 表示对这个人无法判定。留一受试者交叉验证。

### 结果

8 种「分类器 × 特征」组合，两臂均值之差：

```
C1_logreg × F1_min      +0.0137
C1_logreg × F3_raw10    +0.0092
C2_tree   × F3_raw10    +0.0037
C4_hgb    × F3_raw10    +0.0009
C5_svm    × F3_raw10    −0.0020
C3_forest × F3_raw10    −0.0053
C4_hgb    × F2_cheap4   −0.0072
C6_mlp    × F3_raw10    −0.0138
```

**最好的一个 +0.014，一半为负。** 逐受试者层面 79/80 人落在 0.50–0.52，唯一例外是
`1142`（0.717）。

### 这个零结果是测出来的，不是测不出来

同一套面板，两个对照：

```
copy_paste（构造上逐字记忆）   0.82   算术上限 0.816   ← 灵敏度
负对照（正例集其实也不含该人）  0.50                    ← 特异度
```

`copy_paste` 有放回抽样使 1 − e⁻¹ = 63.2% 的窗口逐字放出，
`0.632×1.0 + 0.368×0.5 = 0.816`。读到 0.82 是**通过**。

**没有这两条，「没有泄漏」和「测不出泄漏」无法区分。**

## 七、问题二：outlier 是否与 normal 不同

问题是：**用 outlier 训练出的生成器，其生成内容是否更容易暴露 outlier。**
测量对象是生成出来的样本，不是真实数据本身。

### 组间：两臂的 gap 分布是否分开

**方法**：比较「见过 t 的模型」与「没见过 t 的模型」发布的样本，哪个离 t 更近。

```
d(t, S) = mean_i ( min_k  ‖R_t[i] − S[k]‖ / √F )
          └ 对 t 的每个真实窗口，取到 S 中最近样本的距离，再平均 ┘

gap = d(t, S_base) − d(t, S_include_t)
```

gap 为正 = 见过他的模型放出的样本离他更近 = 该人的信息进入了模型。

**这不是攻击**——它需要两个模型，现实攻击者拿不到。它测的是**生成器的性质**：把一个人
加进训练集，输出会不会朝他偏。

**指标**：P(随机一个 outlier 的 gap > 随机一个 control 的 gap)。

```
           rep1    rep2    rep3
AUC       0.680   0.690   0.670
均值 0.680   SD 0.010   95% CI [0.655, 0.705]   单侧 p ≈ 0.0005
```

**幅度**：AUC 是秩统计量，不携带量级。实际的中位 gap 是异常组 0.000300、对照组
0.000198——相当于绝对距离的 **0.27%** 对 **0.11%**。

**对度量方式的依赖**：`min` 归约（最近的那个合成样本有多近，记忆化的读数）三组都给
0.67–0.69；`mean` 归约（离整个合成分布多远，分布拟合的读数）三组都在 0.43–0.59。
成员记忆本就该体现在前者——模型记住一个人，表现为**某个样本特别接近他**，而不是整个
分布偏移。这个方向是可以事先从机理预期的。

### 个体：每个人各自泄漏多少

```
逐受试者 AUC_t = P(d_out > d_in)，在此人自己的窗口上取秩

  outlier 均值        0.5129  (n=20)
  normal  均值        0.5018  (n=60)
  outlier 剔除 1142   0.5061  (n=19)
  1142                0.6427
```

两组均值差 0.0111，**剔除 1142 后只剩 0.0043——61% 的差异来自一个人**。

## 八、两个问题的答案

**问题一（威胁）**：现实攻击者做不到。最强的攻击组合只把两组分开 +0.014，79/80 人的
个人 AUC 在 0.50–0.52。而仪器本身在会记忆的生成器上读 0.82、在负对照上读 0.50，
所以这是一个**测出来的零**。

**问题二（科学）**：生成器对 outlier 的响应确实系统性更强——把一个 outlier 加进训练集，
放出的样本朝他偏的程度大于对照，组间 AUC 0.680，三次独立重复。但这个差异的**绝对幅度
可忽略**（距离变化 0.27% 对 0.11%），且个体层面 61% 的差异来自一个人。

**可发表的表述**：有界的安全性结果——成员泄漏可测量、有系统性、但量级可忽略，
除了一个人以外。

## 九、两个后续方向

### 方向一：单 CGM 的信息是否不够 → 多通道

原始文件有 37 列。时变的数值通道（非零率指非空格子中不为 0 的比例）：

| 通道 | 非空 | 非零 | 判读 |
|---|---|---|---|
| CGM | 0.898 | 1.000 | — |
| insulin | 0.965 | 0.767 | **精确等于 basal + bolus**，逐行验证 |
| basal | 0.936 | 0.751 | 第二条连续轨迹 |
| bolus | 0.944 | **0.066** | 事件通道，93% 是零 |
| heartrate / steps | 0.007 | — | 13 / 12 人，不可用 |

`cohort.py` 里「胰岛素通道会滤掉 63% 受试者」的说法**不成立**，实测 4.7%。

**三通道实验（CGM + basal + bolus，未按体重归一化）的结果：**

- outlier 名单变了：单通道 37 人、三通道 20 人，交集 15，Jaccard 0.357；
  九个能看到通道的方法各自的前 5% 被替换 76%–97%
- **生成质量变差**：判别准确率 0.65–0.68（单通道是 0.50）
- **成员信号在 CGM，不在 basal**：组间 AUC CGM 0.735、CGM+basal 0.731、bolus 0.632、
  三通道 0.581、**basal 0.393**
- **加通道稀释信号**：1142 从 CGM 单通道的 0.636 掉到 CGM+basal 的 0.508，
  掉出自己的置信区间 [0.615, 0.658]

**质量问题的成因已定位到 bolus**：单独用「每个窗口里 bolus 落在零附近的比例」这一个特征，
区分真假的准确率是 **0.74**，高于完整判别器的 0.60。高斯扩散过程无法产生重复的精确常数。

**排除的两个解释**：不是训练步数（损失两万步收敛，后 7 万步只改善 1.6%）；
不是容量（128→256 参数量 3.8 倍，判别准确率 0.595→0.582 无趋势，跨宽度波动比同宽度
噪声还小一半）。

三通道活动跑到 **44/123 停止**：墙钟按单通道的 5.35 h/模型 估算，实际 8.71 h
（贵 1.63 倍，**全部在训练侧**，采样几乎不变），每条通道都被砍。

**当前修正**：改为两通道 **CGM + basal/kg**（与第一阶段群体实验的约定一致）。
`weight` 单位是**磅**（官方字典），除以 2.20462 换算；1,262 人中 54 人无体重记录被剔除，
换算后体重范围 9.5–137 kg，全部生理合理。

### 方向二：单天信息是否不够 → 多天窗口

**⚠ 这个假设已被独立否定。** 用 `copy_paste` 作攻击上限的标尺（它的上限由自举抽样决定，
与生成器拟合能力无关）：

| 窗口 | 逐受试者 AUC | 中位 gap |
|---|---|---|
| 1 天 | 0.8187 | 0.0680 |
| 7 天（连续） | 0.8147 | 0.0917 |
| 14 天 | 0.8229 | 0.0951 |
| 21 天 | 0.8236 | 0.1047 |
| 理论上限 | 0.816 | |

**从 1 天到 21 天，攻击上限恒定在 0.811–0.824。** gap 幅度涨 54%（长窗口被记住时更突出），
但被记住的**比例**始终是 63.2%，而秩统计量只看比例。

**硬约束**：完整日大多不连续，中位受试者最长连续段 **8 天**。日历上连续的整周 809 人、
两周 40 人、三周 11 人——14 天和 21 天凑不出设计，只能用「拼接」构造。

**七天生成实验（CGM 单通道，h96）**：

```
组间 AUC    0.72     p = 0.052
逐受试者    outlier 0.5943 / normal 0.4881 / 剔除1142 0.5493 / 1142 = 1.0000
```

**这批数字不可读，因为生成器没拟合上。** 判别器能把它的样本和真实数据分开——但支撑这个
判断的「0.9475」本身是不可复现的单次抽样，见 `docs/PITFALLS.md` §16：判别器 GRU 的权重
初始化从未被 seed，读数取决于同一进程里先评过几个模型。同一份样本文件读到过
0.9475 / 0.5908 / 0.6483。

改成八次重启、固定子采样、只动初始化之后：

| 模型 | min | 中位 | **max** | 跨度 |
|---|---|---|---|---|
| copy_paste 七天（锚点） | 0.4950 | 0.5067 | 0.5100 | 0.0150 |
| **h256 七天 @ 22k 步** | 0.4875 | 0.5242 | **0.5508** | 0.0633 |
| h96 七天 @ 34k 步 | 0.4792 | 0.6383 | **0.8442** | 0.3650 |
| **h96 七天 @ 22k 步** | 0.4967 | 0.5538 | **0.9883** | 0.4917 |

**结论：是容量，不是数据量。** 最后两行在同一步数下比，只剩宽度这一个变量：窄模型被分辨
到 0.988，宽模型只到 0.551。过训练的解释同时被排除——h96 训得**更少**反而**更可分**。

**这改变了方向二的定性。**「单天太短」仍然被否定（copy_paste 的攻击上限从 1 天到 21 天
恒定在 0.811–0.824，这个测量不涉及 DiM-TS）。但「更长窗口会不会让生成器记住更多」这个
问题**从来没有被真正测过**——之前是在一个表达不了这批数据的模型上问的。已用 h256 重启
同一个 21 模型试点（22,000 步，损失从 16k 起持平；`sample_batch=100`，1000 会 OOM；
6.60 h/模型，139 GPU·h），2026-08-18 10:50 提交。

## 十、方法学发现（可独立成段）

### 1. 通道的身份信息量与它的泄漏量无关

真实数据里，一天的数据认出本人的 top-1 命中率（同 study 内比对，按体重归一化）：

```
仅 basal/kg   34.2%   （59 倍随机）
仅 CGM         1.6%   （2.7 倍）
```

**basal 携带的身份信息是 CGM 的 22 倍，却对成员泄漏毫无贡献**（组间 AUC 0.393 对 0.735）。

这条对**选通道**有实际用处：不能用「哪个通道更能识别人」来预测「哪个通道更会泄漏」。
基础率是被编程设定的定型量，生成器学会人群里几种模板即可，不需记住个体；
CGM 是特异的噪声轨迹，复现某人只能记住他。

体型不是原因：按体重归一化后这个比值从 19 倍**升到** 22 倍，未被除的 CGM 通道读数
不变（1.57% → 1.58%）作为内部对照。

### 2. 多通道攻击必须分通道报告

摊平成一个欧氏距离等于假设通道同质。`min` 归约在联合空间选最近样本，
加入不带信息的维度会改变选中哪个样本，从而稀释信号。

### 3. 判别准确率是可分性的下界，必须报多次重启的最大值

`discriminative_score` 只 seed 了子采样和批次顺序，判别器 GRU 的权重初始化用的是全局
RNG，所以同一份样本的读数取决于进程里的评分顺序（`docs/PITFALLS.md` §16）。

修好之后暴露出的结构比 bug 本身更有用：**生成器真的好时，分类器每次都收敛到 0.50，跨度
0.015–0.06；有可分特征时，读数分成两坨，跨度 0.37–0.49**。分类器要么找到破绽，要么优化
失败。所以单次读数低不能证明质量好，单次读数高却足以证明可分。该报的是最大值加跨度；
取平均会把「成功的分类器」和「失败的优化」平均掉。

这条给项目里其他判别准确率加了限定：三通道的 0.553 / 0.653 / 0.677、宽度扫描的
0.582–0.643、以及「同宽度三个模型跨度 0.124」——那 0.124 里有多少是度量本身的抖动，
目前没有分离。

### 4. 1142 的泄漏强度随生成器失败程度单调上升

| 条件 | 判别准确率 | 1142 的 AUC |
|---|---|---|
| 单通道单日 | 0.50 | 0.6427 |
| 三通道单日 | 0.65 | 0.6358 |
| 七天单通道 | 0.95 | **1.0000** |

穿过队列重建、主键修正、通道更换、窗口长度更换之后，**这个人始终排在最前面**。

⚠ 待区分：AUC 1.000 是**记忆**还是**分布偏移**。前者是「模型记住了他的数据」，
后者是「训练集里有没有他会改变模型的整体输出」，隐私含义不同。
