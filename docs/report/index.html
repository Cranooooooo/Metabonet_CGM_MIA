02

两个问题，两套度量

这项研究回答两个不同的问题。它们的数据、特征、指标都不一样， 最常见的误读就是拿其中一个的数字去回答另一个。

问题一 · 威胁

现实攻击者能否判定某人在训练集里？

攻击者有什么
一份发布出的合成数据集，和某个人的真实记录。没有「没训练他的那个模型」——现实中不存在。
特征
每个窗口对合成集算 10 个距离量：欧氏族、k 近邻族、余弦族。
指标
逐受试者 AUC，留一受试者交叉验证。0.5 = 判定不了。
答案
做不到。最强组合 +0.014，79/80 人在 0.50–0.52。
问题二 · 科学

outlier 是否比 normal 更容易被生成器记住？

需要什么
同一个人的两个模型：见过他的、没见过他的。这是研究工具，不是攻击。
统计量
gap = 到「没见过」的距离 − 到「见过」的距离。为正说明信息进入了模型。
指标
P(随机一个 outlier 的 gap > 随机一个对照的 gap)。0.5 = 无差别。
答案
是的，但幅度极小。0.664，三次重复，而距离只变了千分之三。

03

gap 是怎么算出来的

拖动滑块，看「模型记住这个人」的程度如何改变两个距离。 每个点是一个合成样本，星号是这个人的一个真实窗口。

d_IN 与 d_OUT

gap = d_OUT − d_IN。我们取的是最近的那个合成样本的距离—— 模型记住一个人，表现为某个样本特别接近他，而不是整个分布朝他平移。

05

问题二：效应存在，但小到可忽略

三次独立重复，剔除 1142 前后

1142 是唯一一个个人 AUC 明显偏高的受试者。 如果结论只是被他一个人撑起来的，剔除后应该塌到 0.5。

换一种距离定义，结论会变吗

六个变体全部计算，但哪个算数是事先在正对照上冻结的。 分野在横轴（如何从合成集合里选样本），不在纵轴（如何汇总这个人的窗口）。

06

四个走不通的方向

每一个都曾经是「也许是因为⋯⋯」的猜想，每一个都被实测否定。 否定结果同样是结果——它们把可能的解释一个个划掉。

窗口太短？——不是

用逐字复制的生成器作标尺，它的检测上限由抽样比例决定，与拟合能力无关。

模型太小？——不是

纵轴是判别器区分真假合成数据的准确率，0.5 最好（完全分不出）。 每个宽度训一个模型，预算相同。

通道太少？——加了反而更差

同一批模型、同一套攻击，只改保留哪些通道。左：组间 AUC。右：真实数据里的可识别性。

第四个：训练不够久？——也不是。 损失在两万步收敛，之后 7 万步只改善 1.6%。七天窗口那一轮我最初按 epoch 对齐只训了 3,700 步，那是欠拟合 20%，作废重训到收敛后结论不变。

07

结论

可发表的表述

有界的安全性结果：在 CGM 生成任务中，成员泄漏是可测量的、有系统性的， 但量级上可忽略。

不能说成「没有 MIA 问题」——那样无法解释 0.664 是什么； 也不能说成「outlier 可被识别」——证据不支持，最强的攻击只把两组分开 +0.014。

三件支撑这个结论的事

论断证据为什么可信
效应存在0.664 三次独立重复（0.663 / 0.674 / 0.655），剔除极端个案后仍成立
量级可忽略0.27% vs 0.11% 距离的相对变化；79/80 人的个人 AUC 在 0.50–0.52
零结果是测出来的0.82 / 0.50 同一套仪器在会记忆的生成器上读 0.82（上限 0.816），在负对照上读 0.50

方法学上可以独立成文的两点

发现 A

可识别性 ≠ 可记忆性

不能用「哪个通道更能认出人」来预测「哪个通道更会泄漏」。 basal 的身份信息是 CGM 的 22 倍，泄漏贡献却是零。

发现 B

多通道攻击必须分通道报告

把通道摊平进一个欧氏距离等于假设它们同质。 加入不带信息的维度会改变「最近样本」是哪一个，从而稀释真实信号。
