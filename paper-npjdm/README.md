# paper-npjdm

Target: **npj Digital Medicine**, Collection *"Synthetic Clinical Data and
Privacy-Preserving Frameworks for Trustworthy Health AI"*
(<https://www.nature.com/collections/gggjgihcjj>), deadline **2027-07-01**.

* `STRUCTURE.md` — the agreed paper skeleton, modelled on the reference. **Start here.**
* `PAPER_PLAN.md` — section-by-section working notes, the numbers each section must carry,
  the open action items, and the claims we must not overstate. **Read this first.**
* `figs/` — figures.

Scope: **one-day windows only** (`d1_c1`, `d1_c2`). The seven-day cells are deliberately
out of scope for this submission.

The older `../Paper/` directory is a **JBHI / IEEEtran** draft built around a
release-time quantile-editing design that was subsequently retracted
(`docs/MODEL_DESIGN.md` §2.7). Do not carry its "Proposed Generator" section over; the
Introduction and the prior-work paragraphs are the only reusable parts, and under
Nature format the prior-work text belongs in the Discussion.

No LaTeX source yet — the plan is agreed first. This machine has no TeX toolchain
(`pdflatex`, `xelatex`, `latexmk` all absent), so anything written here must be compiled
on Overleaf.
